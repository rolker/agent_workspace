# .agent/user_tier_scripts.txt
#
# The workspace scripts and hooks promoted to the Claude Code user tier
# (~/.claude), so a session started anywhere on this machine can invoke
# them. Consumed by:
#   - .agent/scripts/user_tier_install.sh  (generates the absolute-path
#     permission allow-rules and the PreToolUse hook entries)
#   - .agent/scripts/tests/test_user_tier_guard.sh  (asserts every entry is
#     inert outside a registered root)
#
# The user-tier rule (ADR-0016): an entry may be promoted only if it is
# inert outside the workspace checkout and outside every registered project
# root. In practice each entry either calls `registry_require_root` before
# any repo-affecting action, or carries a `# user-tier: inert` marker
# because it only sets variables and defines functions, or carries a
# `# user-tier: guarded-by:<script>` marker because it is a shim that
# execs an entry that is itself guarded.
#
# Format: one path per line, relative to the workspace root. Blank lines
# and `#` comments are ignored.
#
# Trimmed to what the #317 acceptance loop actually invokes from a project
# cwd. dashboard.sh and register_project.sh are deliberately absent —
# deferred to PR 4 (each row costs a guard call plus a test row).
